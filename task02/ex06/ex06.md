# Part 1
The dtype of img * 1.5 is float64.

The maximum value of the result is 382.5, because the maximum pixel value in the original image is 255, and 255 * 1.5 = 382.5.

# Part 3

The result of `img * 2` has dtype `uint8`.

The maximum value is 254 because uint8 can store values only from 0 to 255. When a value exceeds 255, overflow occurs and the value wraps around.

Unlike `img * 1.5`, which produces a float64 array, `img * 2` keeps the uint8 dtype and can produce overflow.

# Part 4
When multiplying the image by 0.5, the result dtype is float64.

The maximum value is 127.5, because 255 * 0.5 = 127.5.

The image becomes darker because all pixel values are reduced to half of their original values.

# Part 5 - Bonus
The mean of the image is calculated using img.mean().

The formula (img - m) * k + m changes the contrast around the mean.

Pixels below the mean become darker, and pixels above the mean become brighter. Pixels equal to the mean stay unchanged.

The expression img - m can produce negative values. Therefore, converting img to float64 before subtraction prevents unsigned integer overflow.

The result dtype is float64. The result is clipped to the range 0–255 and converted to uint8 for display.
