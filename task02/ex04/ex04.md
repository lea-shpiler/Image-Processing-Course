# Part 2

If the filename is incorrect or the image cannot be read, cv2.imread() returns None.

# Part 3

The first image is displayed with incorrect colors because OpenCV uses BGR order, while Matplotlib expects RGB order. After converting the image from BGR to RGB, the colors are displayed correctly.

# Part 4

The bright areas are different in each channel because each channel represents the intensity of a different color: blue, green, or red. Areas containing more of a specific color appear brighter in that channel.

# Part 5

When the image is loaded using cv2.IMREAD_GRAYSCALE, its shape contains only two dimensions: height and width. The image has one grayscale channel instead of three color channels.
